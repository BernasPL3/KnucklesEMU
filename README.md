# knucklesEMU 🎮

Emulador multi-console simples e leve para Android.

## Consoles Suportados

- NES
- SNES
- PS1
- PSP
- PS2
- Wii

## Recursos

- Interface simples
- Save States
- Controles na tela
- Suporte Bluetooth
- Fast Forward
- Biblioteca de ROMs
- Tema retrô

## Tecnologias

- Kotlin
- Jetpack Compose
- Android Studio

## Estrutura

```txt
app/
 └── src/main/java/com/knucklesemu/
      ├── MainActivity.kt
      ├── EmulatorScreen.kt
      └── EmulatorCore.kt
```

## Compilar APK

Abra no Android Studio e clique:

```txt
Build → Build APK(s)
```

APK gerado em:

```txt
app/build/outputs/apk/debug/
```

## Requisitos

- Android 7+
- 2GB RAM mínimo
